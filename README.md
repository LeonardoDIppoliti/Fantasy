# Fantasy
Fantasy è semplice gioco ispirato al primo zelda
All'esecuzione del progetto viene mostrata la schermata iniziale del gioco e si dovrà scegliere tra 
Start Game Load game e Quit alla selezione di Start game ci sarà un cambio schermata con il personaggio giocante al centro della mappa
## Requisiti
JDK 25 o superiore e 
Gradle 9

## Istruzioni
```bash
git clone https://github.com/LeonardoDIppoliti/Fantasy
cd Fantasy
```
  
## Build ed Esecuzione
build progetto ed esecuzione:
```bash
./gradlew build run
```

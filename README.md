# Fantasy
Fantasy è semplice gioco ispirato al primo zelda il cui scopo è sconfiggere tutti gli slime sulla mappa evitando che la vita scenda a 0

## Requisiti
JDK 25 o superiore e 
Gradle 9

## Build ed Esecuzione
build progetto ed esecuzione:
./gradlew build run

## Uso di strumenti di intelligenza artificiale:

Durante la realizzazione del progetto è stato utilizzato Claude come strumento di assistenza per
discutere sulle scelte di progettazione del progetto legate all'applicazione dei principi SOLID e clean code e alla
revisione a possibili violazioni dei principi SOLID e clean code
